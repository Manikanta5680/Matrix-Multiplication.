# Matrix Multiplication in Java

A simple Java program that performs multiplication of two matrices using 2D arrays and nested loops.

## Features

- Accepts matrix dimensions from the user
- Accepts matrix elements as input
- Checks whether matrix multiplication is possible
- Multiplies two matrices
- Displays the resulting matrix

## Condition for Matrix Multiplication

Matrix multiplication is possible when:

Number of columns in the first matrix = Number of rows in the second matrix.

For example:

A = 2 × 3  
B = 3 × 2

Then:

A × B = 2 × 2

## Technologies Used

- Java
- 2D Arrays
- Nested Loops
- Scanner

## Example

### First Matrix

1 2  
3 4

### Second Matrix

5 6  
7 8

### Result

19 22  
43 50

## How to Run

1. Download or clone this repository.
2. Open `MatrixMultiplication.java` in a Java IDE.
3. Compile and run the program.
4. Enter the matrix dimensions and elements.
5. The multiplication result will be displayed.
